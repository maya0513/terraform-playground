# Terraform Playground

クラウドの知識がなくても、手元のPCだけでTerraformの基本を学ぶ教材です。
普通のファイルの作成から始め、Cloudflare R2に似たファイル置き場をローカルに作ります。
**AWSアカウント・クレジットカード・有料サービスは使いません。**

## 読む順番

| ドキュメント | 内容 |
| --- | --- |
| **1. [準備する](docs/setup.md)** | Dockerの確認、miseでの導入、コマンドの読み方 |
| **2. [5つの実習](docs/tutorial.md)** | 作成 → 変更 → S3への保存 → 変数と複数作成 → 削除・再作成 |
| **3. [片付ける・再開する](docs/cleanup.md)** | 終了時の1コマンド、残るもの、容量の解放、次回の再開 |
| [仕組みとコマンドのリファレンス](docs/reference.md) | 用語、構成、ファイルの役割、設定の詳細。必要になったときに読む |
| [困ったとき](docs/troubleshooting.md) | Dockerの権限、接続エラー、データが消えたとき、片付けの失敗 |

初めての場合は「準備する」から順に進んでください。
すべてのコマンドは、このREADMEがあるフォルダで実行します。

## 終わるときは

```sh
mise run cleanup
```

確認入力なしで、この教材のTerraform管理対象を削除し、Motoのコンテナとネットワークを片付けます。
途中までしか進めていなくても、すでにMotoを停止していても使えます。
自分で編集した設定や入力値、次回に使うイメージとツールは残します。
容量も空けたい場合は [イメージも削除する方法](docs/cleanup.md#ディスク容量も空けたいとき)を参照してください。

## 使う道具

| 道具 | 役割 |
| --- | --- |
| Terraform | 設定と実物の差を調べ、作成・変更・削除する |
| mise | ツールのバージョンをそろえ、便利なタスクを実行する |
| Docker / Compose | Motoをコンテナとして起動する |
| Moto | AWSのAPIを手元で再現する |
| AWS CLI | Motoに保存したファイルを確認する |

Linux環境を想定しています。必要なツールはこの作業環境に導入済みです。
初回のダウンロードにはインターネット接続と空き容量が必要です。
MotoはAWSの一部を再現するものなので、実AWSの全機能を学ぶ教材ではありません。
